# Retail Sales Performance Analysis

A beginner-friendly Python analytics project using a generated sample retail dataset.

## Questions explored
- How does revenue change month by month?
- Which products generate the most revenue?
- Which regions contribute the most revenue?
- How many orders and units were recorded?

## Run
```bash
python -m pip install -r requirements.txt
python analyze_sales.py
```

The script creates `outputs/` with the generated CSV data, summary tables and PNG charts.

## Dataset note
The data is synthetic and generated by the script. It is not real company or customer data.
